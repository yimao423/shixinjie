====================================================
拾心界 · 一起听歌  使用说明
====================================================

【这个功能是什么】
在「拾心界」聊天界面，加号(+)菜单第二页新增了「一起听歌」：
  - 可以导入网易云歌单（粘贴歌单链接或歌单 ID）
  - 也可以在面板里直接搜索网易云歌曲
  - 开启「和 TA 一起听」后，聊天对象会跟着一起听，
    并会在播放中途主动「切歌 / 暂停 / 点评」，
    这些动作会以对方消息的形式出现在聊天里。

【分两层：本地服务 + 前端面板】
1) 本地音乐服务（music-server/）
   网易云接口是跨域、且需要登录态的，纯前端页面拿不到。
   所以这里放了一个零依赖的 Python 小服务（借鉴 eryu 的
   网易云代理思路），负责搜索 / 导入歌单 / 下载音频缓存，
   供前端通过 http://127.0.0.1:9801 调用。
2) 前端面板（已接入拾心界）
   index.html 加号菜单「一起听歌」入口
   + js/listen-together.js（面板逻辑 + 一起听互动）
   + css/pages-listen.css（面板样式）

【怎么用】
1. 先启动本地音乐服务（二选一）：
   A. 双击  music-server/start.command
   B. 终端运行：python3 music-server/music_server.py
   （当前已在使用，直接跳过这步）
2. 打开拾心界（双击 index.html 即可），进入任一对象聊天室。
3. 点输入框旁边的「+」加号，翻到第二页，点「一起听歌」。
4. 粘贴网易云歌单链接或 ID 点「导入」，选一首开播；
   或切到「搜索」直接搜歌点「+」播放。
5. 打开「和 TA 一起听」开关 —— 对方会跟着听，
   播放中途会随机 切歌 / 暂停 / 点评。

【关于网易云登录（可选项，强烈建议）】
- 不配置：能播放网易云上的免费歌曲（歌单大部分免费歌可播）。
- 配置后：能播放需要登录 / VIP 的歌曲。
配置方法：在 music-server 目录新建 .netease_cred 文件，内容一行：
    MUSIC_U=你的网易云登录Cookie
（Cookie 获取：登录 music.163.com 网页版，按 F12 ->
 Application -> Cookies -> 复制 MUSIC_U 的值。
 本文件只保存在你电脑本地，仅用于请求网易云接口。）
改完 .netease_cred 后重启 music_server.py 生效。

【接口一览（本地服务）】
  GET /health                 健康检查
  GET /search?q=关键词         搜索歌曲
  GET /playlist?id=歌单ID      导入网易云歌单
  GET /song/url?id=歌曲ID      获取并缓存音频，返回 /file/<id>.mp3
  GET /file/<id>.mp3           带 Range 的本地音频
  GET /lyric?id=歌曲ID         歌词（预留）

【停止服务】
  双击 music-server/stop.command，或终端执行：
  pkill -f music_server.py

【常见问题】
- 面板提示「未检测到音乐服务」：说明 start.command 没运行，
  先启动它再刷新页面重新打开面板。
- 某首歌提示无法播放：该曲需登录/VIP，配置 cookie 后可播。
- 浏览器自动播放限制：首次需要手动点一次播放按钮，
  之后角色切歌/暂停都会正常生效。
- 音频缓存：下载过的歌缓存在 music-server/cache/，
  可手动删除以释放磁盘空间。
